Duckiebot Route Planner

Click a start tile, set which way the bot points, click a destination. Plans with the same A* that runs on the robot.

Step 1. Click the tile the bot is sitting on.

centre line (two lanes) lane edge red stop line start destination route (right-hand lane)

Each road carries two lanes split by the yellow dashed centre line. The blue route is drawn in the right-hand lane - the one the bot actually drives - with arrows for direction. Red marks show which approach has a stop line. U-turns are impossible: the map has no transition that lets the bot leave an intersection the way it came in.

Which way is north? North just means toward row 0, the top of this map. It is not a real compass direction. To match the map to the real track, find the only 4-way intersection (row 4, col 3) and the T-junctions, then rotate this picture in your head until it lines up with the room. Whatever direction "up" ends up pointing is north.
